# Katkıda Bulunma Rehberi

Teşekkürler! Katkıda bulunmak isterseniz lütfen şu adımları takip edin:

1. Depoyu fork edin ve yerelde bir branch oluşturun.
2. Değişikliklerinizi küçük ve açıklayıcı commit mesajlarıyla yapın.
3. Test ekleyin veya mevcut testleri çalıştırın (varsa).
4. Pull request açmadan önce README ve CONTRIBUTING talimatlarına uyduğunuzdan emin olun.

Kod katkıları, hata raporları ve dokümantasyon iyileştirmeleri çok değerlidir.

İletişim: GitHub Issues üzerinden iletişim kurabilirsiniz.
