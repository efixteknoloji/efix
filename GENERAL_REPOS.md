# Genel Repositoriler

Aşağıda AI/ML ve ilgili alanlarda faydalı bulduğum bazı açık kaynak projelerin kısa bir listesi var. İsterseniz bu repolardan seçtiklerinizi alt dizinlere klonlayıp örnekler, açıklamalar veya entegrasyonlar ekleyebilirim.

- https://github.com/tensorflow/tensorflow — TensorFlow
- https://github.com/pytorch/pytorch — PyTorch
- https://github.com/huggingface/transformers — Hugging Face Transformers
- https://github.com/openai/CLIP — CLIP (Contrastive Language-Image Pretraining)
- https://github.com/ultralytics/ultralytics — YOLO / Ultralytics
- https://github.com/rasbt/LLMs-from-scratch — LLMs from scratch (eğitim)
- https://github.com/mlabonne/llm-course — LLM course
- https://github.com/microsoft/ML-For-Beginners — ML For Beginners
- https://github.com/eriklindernoren/ML-From-Scratch — ML From Scratch
- https://github.com/f/prompts.chat — Prompts.chat (prompt koleksiyonu)
- https://github.com/qdrant/qdrant — Qdrant (vektör veritabanı)
- https://github.com/rasbt/LLMs-from-scratch — LLM eğitim örnekleri

Not: Listeyi sizin isteğinize göre daraltabilirim veya proje açıklamaları ekleyebilirim.
